
🧮 Calculadora de IMC

Projeto desenvolvido para calcular o Índice de Massa Corporal (IMC) de uma pessoa com base no seu peso e altura.

📌 Sobre o projeto

A aplicação recebe o peso (kg) e a altura (m) do usuário e realiza o cálculo do IMC utilizando a fórmula:

IMC = peso / (altura × altura)

Após o cálculo, o sistema apresenta o resultado e sua respectiva classificação.

🚀 Funcionalidades
Informar peso e altura;
Calcular automaticamente o IMC;
Exibir o resultado do cálculo;
Informar a classificação do IMC;
Interface simples e intuitiva.
📊 Classificação do IMC
IMC	Classificação
Abaixo de 18,5	Abaixo do peso
18,5 – 24,9	Peso normal
25,0 – 29,9	Sobrepeso
30,0 ou mais	Obesidade

Observação: a classificação acima é uma referência geral e não substitui uma avaliação realizada por um profissional de saúde.

🎯 Objetivo

Este projeto foi desenvolvido com o objetivo de praticar conceitos de lógica de programação, cálculos matemáticos e interação com o usuário utilizando PYTHON(Flet).
